# Initial Release - v01.00

This is the first public release of the PS Vita Windows XP Extended Theme.

This theme has been built to utilize the Extended Format, allowing custom icons for both official system apps and popular homebrew, bringing a Windows XP Luna luna inspired aesthetic to your PS Vita.

## Features Included in v01.00

* **System App Icons:** Custom icons for core Vita applications.
* **Homebrew & Game Icons:** Custom icons mapped to 25 popular homebrew tools and games.
* **Authentic Audio & Visuals:** Classic Windows XP wallpapers and the original setup background music ("Velkommen").

## Important Reminder

Because this is an Extended Theme, you **must** apply it using **Theme Manager EX**. Standard installation via the official Vita Settings app will not apply the homebrew icons. Ensure "Enable Unsafe Homebrew" is checked in your HENkaku settings.
